# Intelligent Academic Prerequisite Advisor (IAPA)

## Project Overview
The **Intelligent Academic Prerequisite Advisor** is a logic-based reasoning engine designed to solve the common student problem of navigating complex course hierarchies. Instead of manually checking thick academic handbooks, this tool uses **Knowledge Representation** and **First-Order Logic** to instantly verify if a student is eligible for a specific course based on their academic history.

This project was developed as a Capstone **Bring Your Own Project (BYOP)** to demonstrate the practical application of AI logic and production rules.

## Features
- **Declarative Knowledge Base:** Stores course data and prerequisite dependencies in a structured format.
- **Logic Inference Engine:** Implements logical conjunction (AND) to verify multiple requirements.
- **Input Normalization:** Handles case-insensitive inputs and whitespace for a robust user experience.
- **Instant Feedback:** Provides clear "Success" or "Denied" messages with details on specifically which prerequisites are missing.

## Built With
- **Language:** Python 3.x
- **Concepts:** Formal Logic, Knowledge Representation, Production Systems.
